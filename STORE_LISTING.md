# Store listing

## Product name

MP4 to MP3 & Audio Converter

## Short description

Turn videos into MP3s and convert audio between MP3, M4A, WAV and FLAC. Offline, nothing uploaded.

## Description

You have a video and only want the sound: a lecture, a song, a voice note, a recording of a meeting. Or you have audio in a format your phone, car or editor won't play.

MP4 to MP3 & Audio Converter pulls the audio out of video files and converts audio files between formats. Drop files or whole folders on the window, choose MP3, M4A, WAV or FLAC, and press Convert. It works offline: your files never leave your PC.

It converts for free, three files per run, with no trial that runs out and no watermark. An optional one-off unlock (£4.99, bought on our website) removes the three-file limit for large batches.

What it reads: MP4, MOV, MKV, AVI, WMV, WebM, 3GP, M4A, AAC, MP3, WAV, FLAC and WMA.
What it writes: MP3, M4A (AAC), WAV or FLAC.

Useful details:
- Convert a whole folder, including its subfolders, in one go.
- Choose the MP3 or M4A bitrate, from small files to best quality.
- Save next to the originals or into a folder you pick.
- Never overwrites anything. If a name is taken, the new file gets "(2)".
- Surround sound is mixed down to stereo so the file plays everywhere.
- Converts several files at once, so large batches finish quickly.

About formats: the app uses the decoders and encoders built into Windows, so it is small and installs in seconds. OGG and Opus files need Microsoft's free Web Media Extensions; if it is missing, the app says so and opens its Store page. Dolby Digital (AC-3) sound is not supported, because current versions of Windows no longer include that decoder.

No account, no ads, no telemetry.

## Privacy

Stored locally: settings (output format, bitrate, output folder, licence key)
in %LOCALAPPDATA%\Mp3Converter\settings.json. Nothing else is kept.

Network: a version check against GitHub Releases about once a day, which the
user can turn off. No audio, video, file names or usage data are sent anywhere.
